# BR30 Group React Conversion

Paste these files into your Vite React project. CSS is included inside `TopStrip.jsx` as an inline `<style>` block, so no separate CSS file is required.

Main files:

- `src/main.jsx`
- `src/App.jsx`
- `src/pages/Home.jsx`
- `src/components/*.jsx`

Run:

```bash
npm install
npm run dev
```
